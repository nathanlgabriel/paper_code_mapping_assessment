### 🔍 Critical Implementation Details Not Explicitly Stated in the Paper

1. **Cascade Rounding (`genBSreplicator_single_tstep`)**:  
   After applying the replicator equation, profile counts become floats. The code uses a greedy rounding algorithm (`np.around(floattotal)`) to assign integer agent counts while preserving type totals. This prevents population drift but can introduce minor statistical artifacts (acknowledged in code comments: *"eliminating the cascade rounding fixed the statistical anomaly..."*).

2. **Attention Masking in Utility/RL Updates**:  
   When computing payoffs, if either agent has `0` in a signal dimension, that dimension is zeroed out in the interaction (`Aprofile_copy[idx] = 0 or Bprofile[idx] = 0 → both set to 0`). This implements the paper's rule: *"When an agent does not attend to signals... she interacts with all other agents as if they had also broadcast 0."* (Sec 3.3)

3. **Batched Mutation & RNG (`mutations10`, `picks10`)**:  
   The paper describes per-agent mutation and per-timestep urn draws. The code pre-generates 10 timesteps of random masks to avoid Python/Numba overhead inside the main loop. Functionally identical, but optimized for HPC execution.

4. **Assortment Normalization (`find_assort_multipliers`)**:  
   The paper's $H(h,x,i)$ formula yields relative weights. The code scales them so `sum(assort_multipliers[i]) = N`, converting similarity into expected interaction counts. This bridges the continuous assortment equation to discrete population pairing.

5. **Urn Floor Enforcement**:  
   After forgetting decay, any urn count `< 1` is set to `1`. This preserves exploration probability, exactly matching Appendix B: *"For any ball type whose quantity falls below 1 in any urn, that quantity is raised to 1."*

6. **Time-Series Dual Tracking**:  
   Code records both raw counts (`*_time`) and normalized probabilities (`*_time_norm`). The paper only shows normalized equilibrium states, but the dual tracking enables sensitivity analysis and convergence diagnostics not shown in the manuscript.
